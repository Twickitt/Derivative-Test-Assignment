# Тренажёр по взятию производных

Учебный тренажёр по вычислению производных для 10–11 классов и подготовки
к ЕГЭ по профильной математике.

Тренажёр называет допущенную ошибку. Неверные варианты ответа подобраны
под типичные ошибки учеников: не учтена производная внутренней функции,
пропущен знак минус у косинуса. Выбрав такой вариант, ученик читает,
что именно привело к неверному ответу, и видит решение по шагам
с числами из своего задания.

## Возможности

- 24 типа заданий в пяти разделах: базовые правила, произведение и частное,
  элементарные функции (sin, cos, eˣ, ln), сложная функция, применение
  производной. Разделы расположены по возрастанию сложности.
- 60 202 комбинации коэффициентов. Задания формируются при каждом вызове,
  а не выбираются из готового списка. Тренажёр хранит последние 30 заданий,
  поэтому повтор возможен не раньше, чем через 30 других примеров.
- Решение по шагам строится под конкретную сгенерированную функцию.
- Статистика по каждому правилу и кнопка «Отработать правило» для правила
  с наибольшим числом ошибок.
- Два режима: свободная тренировка по разделу или по всем темам сразу
  и марафон из 10 заданий с итогами и затраченным временем.
- Справочник правил, доступный с главной страницы и во время решения.
- Тёмная тема, адаптивная вёрстка, управление с клавиатуры (клавиши 1–4
  и Enter), работа без подключения к сети после первой загрузки.

## Как устроено

Статический сайт без сборки и внешних зависимостей. Открывается и с GitHub Pages,
и двойным кликом по `index.html`.

```
index.html              разметка всех экранов
assets/styles.css       оформление, темы, адаптив
assets/favicon.svg      иконка
assets/js/math-expr.js  ядро: дерево выражений, вычисление, рендер формул в HTML
assets/js/tasks.js      24 генератора заданий: функция, решение, типичные ошибки
assets/js/progress.js   статистика и диагностика (localStorage)
assets/js/app.js        экраны, сессии, проверка ответов, обратная связь
```

Формулы рендерятся собственным кодом (`math-expr.js`): дроби, корни и степени
собираются из HTML и CSS. Подключать KaTeX или MathJax не требуется,
поэтому сайт остаётся лёгким и автономным.

Выражения хранятся деревом и поэтому вычисляются численно. На этом построена
защита от совпадений: если сгенерированный неверный вариант окажется равен
правильному ответу, он отбрасывается.

## Запуск локально

Достаточно открыть `index.html` в браузере. Если нужен полноценный HTTP,
например чтобы проверить поведение как на Pages:

```bash
python -m http.server 8000
```

## Публикация на GitHub Pages

1. Залить содержимое репозитория в ветку `main`.
2. Settings → Pages → Source: *Deploy from a branch*, ветка `main`, папка `/ (root)`.
3. Через минуту сайт доступен по адресу `https://<username>.github.io/<repo>/`.

Файл `.nojekyll` отключает обработку Jekyll, которая этому сайту не нужна.

## Данные пользователя

Статистика хранится в `localStorage` браузера. Данные никуда не отправляются,
аналитики и внешних запросов нет.
